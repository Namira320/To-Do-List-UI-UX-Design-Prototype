# 📱 To-Do List UI/UX Design & Prototype

A comprehensive UI/UX design project and interactive high-fidelity prototype for a modern, feature-rich **To-Do List Application**. Designed with a user-centered approach, focusing on task management, categorization, custom tags, and smooth productivity workflows.

---

## 🛠️ Design Tools & Methods

- **Design & Prototyping Tool:** Figma
- **Design Method & Principles:** 10 Usability Heuristics for User Interface Design (Visibility of system status, user control & freedom, error prevention, minimalist design, etc.)
- **Target Audience / Personas:** Analyzed user pain points and needs for individuals managing busy schedules, commitments, and task organization

## ✨ Key Features & UI Components

- **Authentication System:** Secure login, sign-up, Google login integration, and password recovery (Forgot Password / verification code workflows).
- **Task Management & Categories:** Organized dashboards tracking *Today's Tasks*, *On Going*, *Completed*, *Pending*, and *Canceled* tasks.
- **Custom Tags & Personalization:** Options to create custom tags with customizable text and box color themes.
- **Event & Board Organization:** Ability to schedule events, sort tasks by tags/priorities, and create categorized boards (Personal, Private, Secret, Work, Meeting, Sports, etc.).
- **User Profile & Settings:** Account details management, notification toggles, and language preferences.
